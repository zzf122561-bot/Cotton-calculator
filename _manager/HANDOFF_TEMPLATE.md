# 功能会话向管理员汇报模板

发送到管理员会话 01a0b4f7-a6f2-7d83-a4d5-e4de2fd6999c，开头使用 [FEATURE_MILESTONE]。至少包含：

    [FEATURE_MILESTONE]
    会话/功能：
    状态：进行中 / 可技术复核 / 阻塞 / 用户验收信息
    改动摘要和代码路径：
    建议功能版本号（不自行修改正式版本号）：
    已运行的命令与结果：
    未运行或失败的检查及原因：
    设备/浏览器实际验证范围：
    生成管理员测试包所需条件：
    风险、依赖、待管理员决定事项：

每次重大技术变更或验收结果都主动发消息，不能仅改 MD 等管理员自行发现。消息通道失败时，在 app/MANAGER_OUTBOX.md 或 web/MANAGER_OUTBOX.md 写同样内容并注明发送失败时间；通道恢复后补发。功能会话不得用该模板自行宣布正式发布。
