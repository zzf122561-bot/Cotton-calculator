# 单次测试/正式版本记录模板

每次另存为该版本目录中的 RELEASE.md，不覆盖历史记录。

| 字段 | 内容 |
| --- | --- |
| 产品、渠道和版本 | Android/电脑网页；测试/正式；版本号与候选号 |
| 功能会话与交接消息 | 会话 ID、消息日期、交接记录位置 |
| 源码 | integration 提交完整 SHA；对应正式 main 提交完整 SHA；相关目录和构建配置的差异核对 |
| 产物 | 文件名、字节数、SHA-256、本地绝对路径 |
| Android 签名 | 签名方案、证书 SHA-256、zipalign 结果、包名、versionCode/versionName |
| 自动检查 | 命令、日期、结果；失败或未运行原因 |
| 实际体验验证 | 设备或浏览器、版本、日期、场景、结果；未做则明确写未做 |
| 用户验收 | 原话或明确指令、日期、接受的候选包哈希；未验收则写待验收 |
| 远端同步 | 普通推送的分支和标签、远端完整 SHA、核对日期；未推送则写本地候选 |
| 回滚与依赖 | 上一个可用版本、部署/安装前提、已知限制 |

测试包可以在用户验收前生成，但不得标记“正式”或推送成正式标签。网页的服务器部署不因交接包生成而自动发生；Android 的自动测试编译不等于真机验收。
