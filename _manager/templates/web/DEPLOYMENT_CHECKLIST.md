# 部署验收清单

- [ ] HTTPS 页面首次打开无证书警告，页面与所有静态资源返回 200。
- [ ] `manifest.webmanifest` 的 Content-Type 为 `application/manifest+json`。
- [ ] `sw.js` 的 Content-Type 为 JavaScript，且作用域覆盖应用目录。
- [ ] 页头显示手绘棉花；“使用说明”四张图片全部加载。
- [ ] 默认主题为黑白银；黑白金和自选颜色切换后刷新仍保留。
- [ ] 手摘棉默认输出 14249 元/吨；机采棉默认输出 16987 元/吨。
- [ ] 修改左侧只重算右侧；修改右侧只反算左侧；只聚焦输入框不改变计算方向。
- [ ] “复制测算摘要”生成当前棉种和当前测算；邮件询价正文一致。
- [ ] 联系作者中的电话、邮件和微信二维码正确。
- [ ] Chrome、Edge 等目标电脑浏览器布局、键盘输入和缩放显示正常。
- [ ] 电脑端首次联网后，断网刷新和版本更新均通过。
- [ ] 回滚路径、备份位置和发布版本已记录。

手机端、iOS/iPadOS、主屏幕安装和 Web Clip 自 2026-09-06 起不再维护或验收。
