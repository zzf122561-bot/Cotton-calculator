## 使用规则（本轮新决定优先于旧版方案保存设计）

- 平台使用账号密码管理厂方、厂码、可编辑项目、分享权限、默认配置；每厂一个独立管理账号。新厂权限默认关闭，由平台逐项开放。
- 厂方编辑参数或模板，先预览，再发布。服务器再次检查当前权限和版本，冲突不覆盖。平台默认值只影响新建厂。
- 管理页面有未发布的参数/文案修改时，保存资料权限、换码、切厂、重新载入、创建新厂和改管理密码均先确认放弃；退出后台立即清除当前管理内容及草稿。等待操作期间用原生 disabled fieldset 锁定所有控件，保留各项原有权限；新渲染控件同样受锁定约束。失败不会清空原草稿。
- 棉农先查厂码并确认厂名，再填写联系手机号。手机号进入时必填，仅检查 11 位 ASCII 数字格式，不发短信。独立 contacts 表只保存提交时厂方、手机号和收集时间；同一厂同号去重，不存浏览器身份、客户 ID、最近使用时间或测算关联。
- 厂方仅能查看、导出本厂手机号名单；平台可选择各厂查看。CSV 为带 UTF-8 BOM 的手机号、收集时间、未核验状态三列。手机号不作为身份凭据，不提供手机号找回或跨设备记录合并。
- 浏览器持久身份使用本轮独立的 HttpOnly Cookie，服务端仅存随机令牌摘要；默认 180 天，重新进入时续期；管理登录使用下述独立的当前页面规则。身份仅用于选择当前加工厂及请求次序保护，不关联手机号。
- 当前浏览器身份固定首次进入的加工厂。计算页没有换厂或退出清除身份入口；接口拒绝现有身份加入其他厂，拒绝时不收集目标厂的手机号、不修改关联关系。停用厂的现有身份也不能借此换厂。同厂重入保留身份及请求次序。用户自行清除浏览器数据后属于新的访问身份，手机号不会恢复旧身份。
- 内部计算参数留在服务器；公开价格为籽棉价、期货价、基差和派生皮棉合计。修改籽棉时保留基差反算期货；修改期货时保留基差重算籽棉；修改基差时保留期货。
- 使用 Fraction 精确计算，展示 HALF_UP；籽棉两位小数，期货/基差/皮棉整数元每吨。基差允许负数。输入空白、不完整或结果为负时不能把当前结果加入对比或分享。
- 不再提供保存、历史方案或后台客户方案查看。新库不建立 drafts、calculations、plans、comparisons 表；测算返回后不保存输入、结果或分享文字。原方案和客户接口不再注册，不能仅隐藏前台按钮。
- 比价只用当前页面内存的最多四条快照。图按加入顺序显示籽棉价，各点标价，显示最高/最低及每公斤差额，注明纵轴按范围缩放、不是行情预测。图内按方案编号同时列出期货价与基差（元/吨），不混入籽棉纵轴（元/公斤）。重算和后续参数发布不改写已加入的临时快照；分享使用快照原文。刷新、离开后清空；浏览器前进/后退缓存恢复同样清空。
- 期货、基差和皮棉合计放在同组，窄屏纵向排列；正常结果不显示更新徽章、配置版本时间或重算按钮。输入未完成、请求失败时保留明确提示，失败时提供重新测算入口，恢复成功后隐藏提示和重试按钮。
- 同页刷新配置时保留个人已输入基差；整页刷新按厂方默认值开始新测算。请求带代次和递增 revision，客户端忽略迟到结果，服务端只保留次序数字并拒绝过期请求，不保存价格草稿。
- 不注册 Service Worker，不读写旧版 localStorage，不新增方案持久存储，不离线回退内部计算。断网保留当前输入并禁用当前结果操作。
- Android 不设置后台配置入口是后续 APP 决定；本轮只改 web/，没有改 Android。

## 运行与初始化合同

后台仍使用现有 `api/requirements.lock` 中的 Python 3.12、FastAPI/Uvicorn/SQLite 依赖，没有新增依赖。生产入口为 `api/factory_run.py`，不替换旧 `run_server.py`；旧 Dockerfile 仍打包旧产品，不能把它当作新版完整部署上下文。

由管理员准备**新的独立数据库**和私有初始化 JSON，仅含 `username` 与 `credential`；credential 沿用 PBKDF2-HMAC-SHA256、600000 次、独立随机盐的既有合同。私有材料不得进入静态目录、文档、Git、测试数据或普通镜像。

```powershell
# 由管理员在获授权的目标环境执行；本轮未做真实初始化或部署。
python factory_run.py initialize --database <独立新库路径> --bootstrap <管理员私有JSON路径>
python factory_run.py serve --database <独立新库路径>
```

初始化拒绝任何已有目标库，先在同文件系统临时库完成后用无覆盖硬链接发布；常驻入口不接收 bootstrap、不 seed。`FACTORY_ORIGIN` 必须为实际 HTTPS scheme+authority；`FORWARDED_ALLOW_IPS` 沿用原服务的逐个具体代理 IP 校验，不允许星号/网段。常驻单 worker、端口 8080、无访问日志。反代保留新接口和页面前缀，配置请求大小限制 64 KiB；不能将整个 `web/api` 作为静态目录。

Cookie 使用 Secure/HttpOnly/SameSite=Strict/Path=/v2/factory-api。写请求要求同源 Origin、JSON 和 X-CSRF-Token。普通请求与密码/厂码操作限流，管理登录连续五次失败冷却 30 秒。凭据重置撤销对应管理会话；停用厂停止其计算与配置服务。本轮数据库代次为 `factory-contact-only-20261115`；旧主版库和本轮调整前的 `factory-browser-identity-20261115` 库均被拒绝，无隐式迁移或清理。预览重启只重建本次临时合成库。

## 接口分组

所有路径相对 `/v2/factory-api`，请求模型拒绝额外字段。普通失败仅返回 `detail`，不回显密码、内部配置或数据库路径。

| 路径 | 用途 |
| --- | --- |
| `GET /session`、`POST /logout` | 棉农匿名/持久身份；保留撤销会话接口，计算页不提供退出入口 |
| `POST /code`、`POST /join` | 查厂名、首次登记或同厂重入；只接受有效启用厂码，拒绝现有身份跨厂 |
| `GET /context`、`POST /calculate` | 当前厂公开默认输入、按代次和递增 revision 测算；不存结果 |
| `/manage/session`、`/manage/login`、`/manage/logout`、`/manage/password` | 独立管理登录与本人改密 |
| `GET/POST /manage/factories` | 平台列出/创建厂，厂方只列自己 |
| `PATCH /manage/factories/{id}` | 平台修改资料、启停、参数权限及文案权限；版本检查 |
| `POST /manage/factories/{id}/rotate-code`、`/password` | 平台换厂码、重置厂方管理密码 |
| `GET/PUT /manage/config/{id或defaults}`、`POST .../preview` | 平台默认或本厂参数/模板；预览与发布同一校验 |
| `GET /manage/factories/{id}/contacts`、`.../contacts.csv` | 本厂独立手机号名单与 CSV 导出；每次检查管理范围 |
| `GET /healthz` | 新库就绪下返回 ready；未初始化/旧代次返回 503 |

## 2026-11-16 管理页面临时登录

平台总管理员、厂方管理员登录仅对当前页面有效：刷新、关闭后重新打开、从浏览器前进后退缓存恢复都返回登录。登录成功起服务器绝对有效期为 3600 秒，操作不续期；前端从登录请求开始保守计时，并同时检查墙钟和单调时钟，在定时器、恢复焦点及页面恢复时清除过期内容。后台暂停导致定时器延迟时，服务器仍独立检查时限。

管理 Cookie 保持原名称，但不设置 Max-Age 或 Expires。仅有 Cookie 不能恢复管理权限：成功登录响应仅返回一次页面证明（csrf），只留在当前页面内存；管理请求包括只读配置、联系人和 CSV 都必须携带 X-Page-Proof，写请求另外携带 X-CSRF-Token。服务器仅存页面证明的摘要，使用现有 sessions 表中新 kind 区分新会话。旧八小时 manager 会话不能通过新版本鉴权，不改账号密码、表结构、数据库代次或业务数据。

GET /manage/session 是页面启动/重新连接的会话重置入口：撤销当前管理 Cookie 对应的旧会话，签发匿名管理会话，始终返回 identity:null，不返回旧页面证明。页面离开时立即清除本地管理数据，不依赖关闭时发送请求；下次页面初始化必须完成服务器重置后才能登录。离线退出先清除本地证明、参数草稿、联系人和导出状态，恢复联网后重置服务器会话；旧证明已无法从当前页面取回。普通计算器 visitor Cookie、180 天固定本厂身份和已收集联系人不受管理退出影响。

退出或过期会中止待处理请求并更换页面代次；即使服务器响应迟到，也不能重新显示管理内容、生成导出或触发后续发布。服务器已经接受并完成的写入不因客户端随后退出自动回滚。请求到达保护读写处理器时再次检查证明和绝对过期。

本次只删除入口手机号下面及后台联系人区的两段指定说明，不改变手机号收集、格式校验、去重、导出或身份隔离。新增运行模块 factory/management-session.js 必须随现有运行文件打包，并已加入服务器静态白名单；管理员打包 SOURCE_FILES 需要相应纳入，功能会话不修改管理员脚本。部署更新直接使用现有业务库，不运行 initialize；历史源码或未刷新的旧管理页面在更新后需要重新加载登录。

本次会话测试证据使用 web/build/factory-session-* 独立路径，包含测试时钟、迟到响应、离线退出和本机合成账号浏览器检查；未操作生产账号或数据库。
