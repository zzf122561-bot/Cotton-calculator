# 机采棉成本换算桌面网页版

这是独立衍生版“机采棉成本换算”的电脑端静态网页。它不含后端、分析、广告、第三方 CDN 或运行时依赖，也不读取主版数据。

## 功能范围

- 只提供机采棉的籽棉价与皮棉入库成本双向换算；最后实际修改的价格作为计算依据。
- 参数默认不创建到页面 DOM。通过棉花图片的十击入口完成校验后，参数在价格桥下方原位创建。
- 十击必须从第一次点击起 5 秒内完成；连续错误 5 次后冷却 30 秒。
- 解锁只对当前页面运行会话有效，刷新或关闭后重新锁定。失败次数、冷却与解锁状态都不写入存储。
- 参数修改继续持久化；重新锁定不会清除已保存参数。
- 有效结果可保存为不可变快照，也可直接保存并加入最多 4 条的方案对比；历史支持按备注、日期和两侧价格搜索。
- 历史列表每次只渲染 30 条，可持续“加载更多”，因此大量记录不会一次性扩张 DOM；到达末页时焦点移到首条新记录的操作，避免落在隐藏按钮上。
- 当前结果和历史记录都先进入只读分享预览，再由用户选择复制文本或系统分享。
- 本机管理员可维护普通授权用户和分享模板，并在核验当前密码后修改自己的密码。FYX 只在首次初始化时作为默认普通用户写入一次，主动删空后不会自动恢复。
- 设置入口用于防止误触，不是安全边界。
- 保留使用说明、黑白银/黑白金/自选强调色、联系作者和离线缓存。
- 使用 BigInt 有理数完成精确业务计算，只在显示时采用 `HALF_UP` 四舍五入。

## 独立身份与存储

- Manifest 产品名：`机采棉成本换算`，应用 ID：`./machine-cottoncal`。
- 计算数据键：`cottoncal.machine.v1`；内容只有 `machine` 字段和计算方向。
- 主题键：`cottoncal.machine.theme.v1`。
- 历史键：`cottoncal.machine.history.v1`；对比链接键：`cottoncal.machine.comparison.v1`。
- 分享模板键：`cottoncal.machine.share-template.v1`。
- 普通授权用户键：`cottoncal.machine.users.v1`；一次性初始化标记：`cottoncal.machine.users-initialized.v1`。
- 管理员本地校验材料键：`cottoncal.machine.admin-credential.v1`。未设置本地新密码时沿用静态包内置校验材料；设置后只在当前浏览器的本站数据中生效。清除本站浏览器数据会丢失本地新密码，并恢复静态包内置校验；其他访客和整站不会同步修改。
- 新增持久化内容都有独立 schema/version、严格反序列化和存储异常回退。数据只保存在当前浏览器，不提供云同步或数据搬运入口。
- Service Worker 缓存命名空间：`cottoncal-machine-v1-`。
- 管理员与普通用户密码使用 UTF-8、PBKDF2-HMAC-SHA256 和恒定时间比较；管理员改密要求当前密码、新密码（8～128 个字符）及确认，随机生成新盐，仅保存算法、版本、迭代次数、位数、盐和 verifier，不保存明文。存储失败不报告成功或在本页启用新密码，存储材料损坏或不可读取时管理员校验拒绝解锁。新增或重置普通用户密码会拒绝与当前管理员或其他普通用户凭据冲突，改密与普通用户密码变更由同一个挂起锁串行覆盖冲突校验、凭据生成和持久化。源码不包含真实密码；此本地入口只防误触，不构成强安全边界。
- 解锁主体、失败次数、冷却和管理员页面状态只存在于当前运行会话，刷新后重新锁定。

## 方案账本与分享模板

- 历史快照保存计算方向、全部输入、精确结果、显示结果、保存时间和可选备注；后续修改参数不会重算旧记录。
- 对比按规范化计算内容去重，忽略记录 ID、保存时间和备注；主轨道使用快照精确籽棉单价计算高低、差额和位置，并以两位 `HALF_UP` 显示；删除历史会同步移除对比链接。
- 当前结果加入对比前先做重复与四条上限预检；备注为空时复用最新相同计算历史，备注非空时复用相同计算和相同备注的历史，避免无意义重复记录。
- 分享中的籽棉吨价由快照内的精确籽棉价乘 1000 后 `HALF_UP`，历史列表显示到分钟，分享日期只显示到日。
- 动态分享模块覆盖日期、计算方向、两侧价格和全部机采棉参数，只允许显隐与排序；静态文字和分隔线可增删改和排序，公司名只是普通静态文字。

## 本地启动与技术检查

需要 Node.js，无需安装 npm 包：

```powershell
cd D:\Codex_Project\Codex_cottoncal\web
node .\server.mjs
```

访问 <http://127.0.0.1:4173>。运行全部测试：

```powershell
node --test
```

正常访问跟随系统深浅色；本地视觉检查可临时使用 `?theme=light` 或 `?theme=dark` 固定预览。

检查所有 JavaScript 和 MJS 语法：

```powershell
Get-ChildItem .\js\*.js, .\test\*.js, .\test\*.mjs | ForEach-Object { node --check $_.FullName }
```

桌面 Edge 交互检查使用 1280×900 视口和依赖注入校验器，不接触任何真实密码：

```powershell
$env:EDGE_PATH = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
$env:EDGE_DEBUG_PORT = '9222'
node .\test\browser-check.mjs
```

该检查覆盖锁定、普通用户解锁、同页二次十击进入管理员、退出复锁、记录分页末页焦点、对比、分享、用户变更并发锁、重复控件可访问名称、刷新重锁、浏览器存储和主题。自动化结果与用户验收分别记录。

## 维护与验收边界

网页功能会话只修改 `web/` 内功能代码、文档和测试，不生成 ZIP 或交付材料。正式版本号、交付包、服务器交接和发布记录由管理员负责。

自动化、桌面浏览器检查和用户验收必须分别记录。浏览器检查应覆盖：锁定状态、十击入口、密码遮罩、参数展开、刷新重锁、主题、双向换算与持久化。
