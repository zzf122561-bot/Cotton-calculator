# 机采棉成本换算桌面网页版

本衍生版现在由静态前端与独立 Python 3.12/FastAPI/SQLite API 组成。认证与每位用户的参数、分享模板以服务器为准；本机历史、对比、主题不上传。原纯静态本机鉴权方案已停止使用，后端故障不能回退到它。

## 使用与权限

- 门板选择服务器启用的用户名，再输入该用户门板密码。身份以不可复用 UUID 为准，不以密码全局扫描匹配；不同普通用户可使用相同密码。
- 门板登录可计算、保存本机快照、对比与分享，不能编辑参数或模板。
- 棉花图标第一次到第十次点击需在五秒内完成。服务器识别当前用户一级密码或二级密码：一级展开参数，提供分享编辑/本人改密；二级进入纯用户管理，无参数或模板编辑入口。
- 一级保存参数与模板是显式云端保存，带配置版本。409 冲突不覆盖服务器或本页草稿，重新读取会放弃本页未保存草稿。重新获得焦点会读取最新配置，但不会静默覆盖草稿。
- 分享编辑预览与当前/历史实际分享共用 renderShareText；动态数值取真实快照，只能显隐、排序，不能独立改数字。
- 本人改门板密码核验门板旧密码，改一级核验一级旧密码；二级重置目标密码不用目标旧密码。本人、二级改密均要求确认新密码。
- 二级可创建、改名、启停、删除用户，分别重置门板/一级密码，并验证自身旧密码更改二级密码。改密、重置、启停、删除会撤销相关旧会话；退出/切换立即清空页面。
- 五次失败/三十秒冷却与请求限流由服务器执行，不依赖浏览器时间或刷新。
- 二级密码不得与任何未删除用户的门板/一级密码相同（停用用户仍计入，已删除排除），比较区分大小写；普通用户之间及本人两种密码仍可相同。各改密/重置/创建检查与写入置于同一服务器写事务，拒绝时原凭据和授权保留。
- Cookie 在生产为 Secure、HttpOnly、SameSite=Strict、Path=/v2。提升凭证只驻页面内存，绑定会话/角色/用户；刷新后一级/二级提升丢失，门板 Cookie 可在有效期内保持。
- 断网不能登录、解锁、云端保存；失败不显示成功，无本地密码回退。API 不进入 Service Worker 缓存。

主题仍为银/金/自选强调色与系统深浅色，保留使用说明、作者联系和静态资源离线缓存。双向换算继续使用 BigInt 有理数，只在显示采用 HALF_UP。

## 一次性迁移与本机账本

迁移标记 cottoncal.machine.migration.machine-cloud-20261003 仅移除旧用户、初始化标记、旧凭据、计算参数和分享模板这五类键，不清空站点数据。旧历史/对比/主题保留；失败可重试，不据此恢复旧鉴权。

旧账本仍保留在 cottoncal.machine.history.v1 / cottoncal.machine.comparison.v1，显示为“旧历史遗留区”，不自动分给新用户。新账本使用 cottoncal.machine.user.<UUID>.history.v1 / comparison.v1。同名删后重建的新 UUID 不继承旧账本。清除浏览器数据会丢失本机账本/主题，但不会重置服务器密码或配置。

快照不随参数变化重算；最多四条对比、精确籽棉价格比较、按内容去重、历史搜索/分页、删除同步移除对比链接与分享日期/吨价规则保持。

## 本地技术检查

需要 Node 24 与本目录 api/.venv 的 Python 3.12。后端安装、初始化和部署合同见 [API README](api/README.md)。

在 web/ 运行：

~~~powershell
node --test
$env:EDGE_PATH = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
$env:API_PYTHON = Join-Path (Get-Location) 'api\.venv\Scripts\python.exe'
$env:EDGE_DEBUG_PORT = '9235'
node .\test\browser-check.mjs
~~~

标准 Node 测试没有 EDGE_PATH 时按设计跳过浏览器检查；显式脚本启动仅回环的真实合成 API 与两个隔离 Edge Cookie/存储上下文，不替换鉴权器，不使用管理员真实 bootstrap。覆盖同步、UUID 隔离、409、预览一致、改密/撤销、离线、刷新复锁与本机账本。

api/test_server.py 是测试入口，不得部署。临时数据库/浏览器配置与技术日志仅在 build/。node server.mjs 只供静态布局预览，API 显示 503 维护提示，不能登录；它只允许公开资源，不公开 api/、测试或本机文件。

## 部署与维护边界

公网前端固定 /v2/，API 固定同源 /v2/api/，反代必须保留此前缀。先由管理员准备独立持久数据库、执行一次性私有初始化并核验 API，再切换前端。静态托管只发布 index.html、styles.css、sw.js、manifest.webmanifest、js/、assets/、icons/；api/、测试、venv、build/、私有材料均不属于静态根。

功能会话只维护 app/、web/ 源码与技术检查，不制作 ZIP、交付单或对外 APK，不操作 Git、签名或正式版本号。Docker/Linux、生产 HTTPS/反代、真实初始化、实际部署、真机及用户验收必须由管理员单独记录；本地自动化通过不等于这些验收通过。
